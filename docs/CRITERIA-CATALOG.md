# Каталог критериев подбора

> Справочник для выбора критериев под конкретную вакансию. Система ничего
> не выбирает сама: итоговые веса и обязательность утверждает рекрутер.
>
> Файл сгенерирован из `data/criteria/catalog.yaml`:
> `hirebot criteria --markdown > docs/CRITERIA-CATALOG.md`

## Как читать

| Поле | Значение |
|---|---|
| **Проверяемость** | насколько надёжно критерий виден из резюме |
| **Вес** | предлагаемая важность: 1 (низкая) — 3 (высокая) |
| **Обязательный** | провал даёт жёсткий потолок балла |
| ⚖ | требует решения юриста до использования |

Всего критериев: **49** в 8 категориях.

## Требуют решения юриста

Эти критерии законны только при определённых условиях. До подтверждения юристом не использовать.

### Право на работу в РФ (`work_permit`)

Требование законно для оформления по ТК РФ, но фильтрация по гражданству может быть признана дискриминацией. Формулировать как проверку права на работу, а не как отбор по национальности. Нужно подтверждение юриста.

### Допуск к охраняемым объектам (`security_clearance`)

Применять только если этого требует объект; проверить с юристом.

## Чего в каталоге нет и почему

| Признак | Почему нельзя |
|---|---|
| Пол и гендер | Дискриминация (ст. 3 ТК РФ, ст. 13.11.1 КоАП РФ) |
| Возраст и дата рождения | Дискриминация; возраст не влияет на способность работать |
| Национальность, раса, гражданство как фильтр | Дискриминация. Право на работу проверяется отдельным документом (см. work_permit) |
| Семейное положение и дети | Дискриминация; влияет на планы работодателя, а не на работу |
| Религия и убеждения | Дискриминация |
| Место регистрации и прописка | Дискриминация; проверяется фактическая возможность добираться |
| Фотография | Не относится к квалификации; источник неосознанных предубеждений |
| Состояние здоровья и инвалидность | Дискриминация, кроме случаев, где противопоказания установлены законом для должности |
| Судимость | Допустимо только для должностей, где это прямо предусмотрено законом; требует решения юриста |
